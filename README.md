## 🚀 Quick Start

### ✅ Prerequisites
- [Node.js](https://nodejs.org) 18 or newer

### 1️⃣ Clone
```bash
git clone https://github.com/sourav-07-s/ReactProject--Blog.git
cd ReactProject--Blog
```

### 2️⃣ Install and run
```bash
npm install
npm run dev
```
🎉 Open <http://localhost:5173>
